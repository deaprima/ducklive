Sederhana, tapi lengkap

Otomatis dari chat live

Member baru, gift, dan Super Chat terhitung langsung. Gift ×5 dihitung 5, bukan 1.

Goal dan overlay siap OBS

Daftar goal dengan centang otomatis, timer, alert, dan ticker. Tinggal tempel URL.

Lokal dan terkontrol

Berjalan di komputermu dengan token admin. Ada batas maksimum timer, undo, dan backup.

Mulai dalam 3 langkah

  1. 1

    Unduh dan jalankan

    Buka DuckLive.exe. Halaman Admin terbuka otomatis di browser.

  2. 2

    Tempel URL live

    Pilih sumber (scrape atau API resmi), tempel URL, lalu klik Sambungkan.

  3. 3

    Pasang di OBS

    Tambah Browser Source dengan URL overlay, lalu klik Mulai.

Siap mulai subathon?
