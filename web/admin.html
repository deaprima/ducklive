Pengaturan YouTube API

  1. Di Google Cloud: aktifkan YouTube Data API v3, buat OAuth client tipe Desktop.
  2. Unduh file JSON-nya, ganti nama menjadi client_secret.json, taruh di folder data (tombol di bawah).

40 event terakhir. Undo membatalkan hitungan dan waktu dari satu event.

Panduan cepat

  1. Buka tab Aturan: atur menit per member dan waktu awal, lalu klik Simpan aturan.
  2. Buka tab Goal: tambahkan target, misalnya 50 member untuk "Makan cabe".
  3. Buka tab Tampilan overlay: pilih warna, ukuran, dan perataan sambil melihat preview, lalu simpan.
  4. Buka tab Pasang di OBS: salin URL dan pasang di OBS sebagai Browser Source.
  5. Buka tab Tes & riwayat: coba tombol tes, lihat overlay di OBS bereaksi. Setelah selesai, klik Reset semua.
  6. Saat live: di tab Sumber live pilih Baca live chat, tempel URL live, klik Sambungkan, lalu klik Mulai di atas.
  7. Selesai live: klik Matikan aplikasi di kanan atas. Data tersimpan; saat dibuka lagi timer berstatus jeda.
  8. Tab ini tertutup? Klik lagi ikon DuckLive di Desktop atau Start Menu.

DuckLive sudah dimatikan

Timer dan data sudah tersimpan. Overlay di OBS berhenti update sampai aplikasi dibuka lagi.

Untuk membuka lagi, klik ikon DuckLive di Desktop atau Start Menu. Tab ini boleh ditutup.
